## Краткий итог

Изучены копия рабочей Google Sheets, CSV-выгрузка и расшифровка интервью с заказчиком. Текущая таблица используется как источник AS-IS, но финансовая модель не входит в область продукта.

Утверждены [`ART-00` — реестр источников и решений](analysis/00-source-and-decision-register.md) версии 1.1, [`ART-01` — Vision & Scope](analysis/01-vision-and-scope.md) версии 0.6, [`ART-02` — стейкхолдеры и глоссарий](analysis/02-stakeholders-and-glossary.md) версии 0.3 и [`ART-03` — AS-IS](analysis/03-as-is.md) версии 0.2. `ART-00` v1.1 включает `DEC-036` и `DEC-037`: отдельный агент-планировщик исключён, полный маршрут работает как «исполнитель + независимый ревьюер», а облегчённый маршрут сохраняется без обязательного ревьюера. `ART-03` v0.2 переработан по `DEC-036`, прошёл независимое review `PASS` (`0/0/0`) и утверждён владельцем.

## Подтверждённые решения

- полный целевой корпус включает рабочую таблицу, действующий ассортимент и другие архивы;
- для полного корпуса коллеги могут подготовить однократный проектный датасет;
- прямой доступ к основной БД и регулярная синхронизация для MVP не обязательны;
- первым результатом выбран прототип на текущей таблице;
- прототип использует только строки с доступным источником изображения;
- интерфейс локальный, однопользовательский и без авторизации;
- выдача содержит до десяти кандидатов;
- результат разделён на итог запроса `NEW / SAME_PRODUCT / UNCERTAIN` и отношение к кандидату `VARIANT / UNRELATED / N/A`;
- `ANALOG` исключён из области продукта;
- операционные роли — `Инициатор товара` и отдельный `ЛПР по товару`; аналитик исключён из пула операционных ролей;
- решение всегда принимает человек.
