# Журнал архитектурных решений

> Архитектурный этап ещё не начат. Принятые продуктовые и процессные решения находятся в [`ART-00`](../analysis/00-source-and-decision-register.md); текущая точка продолжения — в [индексе анализа](../analysis/README.md).

В этом каталоге будут храниться Architecture Decision Records (ADR).

## Статусы

- `proposed` — решение предложено;
- `accepted` — решение принято;
- `deprecated` — решение больше не рекомендуется;
- `superseded` — решение заменено другим ADR.

## Шаблон имени

```text
NNNN-short-title.md
```

Например: `0001-modular-monolith.md`.

## Шаблон ADR

```markdown
# ADR-NNNN. Название

- Статус: proposed
- Дата: YYYY-MM-DD

## Контекст

Какая проблема или ограничение требует решения.

## Рассмотренные варианты

1. Вариант A.
2. Вариант B.

## Решение

Какой вариант выбран и почему.

## Последствия

Положительные и отрицательные последствия решения.

## Условия пересмотра

Какие измерения или изменения контекста требуют пересмотра.
```
