# `ART-00`: реестр решений и подтверждённых плановых фактов

> [`ART-00`](../00-source-and-decision-register.md) · [Источники](sources.md) · [Governance](../governance.md)

## 6. Реестр принятых решений

Решения аналитического процесса `DEC-010`–`DEC-021` входят в ратифицированный пакет `PKG-ANALYSIS-001`. Ранние продуктовые решения `DEC-001`–`DEC-009` восстановлены из discovery-контекста и явно подтверждены владельцем единым пакетом в `SRC-017`. Решение `DEC-002` заменено решениями `DEC-030`/`DEC-031`, а `DEC-023` — решениями `DEC-025`–`DEC-027`. Правила исполнения уточнены `DEC-035`–`DEC-037`, `DEC-041` и контрактами `DEC-047`–`DEC-048`.
