## Неподвижные границы

- Restricted XLSX, строки, `product_id`, локаторы, изображения, полный JSON-отчёт, runtime-env, секреты и runtime-данные не попадают в Git, документы или чат.
- Не менять `main`, не выполнять merge/push, не удалять исходный XLSX, старые Docker volumes или runtime-контур и не начинать Gate 3.
- Фактический результат Gate 2 требует независимого read-only review, затем отдельного явного owner approval. Ни review, ни этот файл не являются approval.
