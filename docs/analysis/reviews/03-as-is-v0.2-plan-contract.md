# План-контракт переработки `ART-03` AS-IS v0.2

> [ART-03](../03-as-is.md) · [ART-00](../00-source-and-decision-register.md) · [Текущий контекст](../current-context.md)

| Поле | Содержание |
|---|---|
| Исполнитель | Codex |
| Цель | Перевести `ART-03` на человекоориентированную трассировку, не меняя подтверждённое содержание AS-IS. |
| Нормативные входы | `ART-00` v1.1, `APPROVED_BY_OWNER`: §2.3, `DEC-035`–`DEC-037`; `ART-01` v0.6 и `ART-02` v0.3; исправленная `ART-03` v0.1 и её независимое review. |
| Доказательные входы | Только уже использованные `SRC-001`, `SRC-003` и ограничение доступа `SRC-015`; новые источники и проверки production-среды не выполняются. |
| Запрещённые выводы | Не добавлять TO-BE, UI, архитектуру, требования, новый бизнес-факт, правило сопоставления, семантику формул или полей таблицы; не отождествлять `ДУБЛИКАТ AS-IS` с целевым `SAME_PRODUCT`. |
| Ожидаемый результат | `ART-03` v0.2 в статусе `DRAFT`: локальные `ASIS-*` выведены из употребления; сохранены только значимые междокументные `GAP-*`, компактные ссылки на источники, границы доказательств и история изменения. |
| Самопроверка | Проверить отсутствие `ASIS-*` и новых небазовых ID, сохранение фактов и ограничений v0.1, действительность ссылок на `SRC-*`/`DEC-*`/`GAP-*`, разделение AS-IS и TO-BE, структуру Markdown и Mermaid. |

Этот контракт составлен исполнителем в рамках полного маршрута `DEC-035`/`DEC-037`; отдельный агент-планировщик не используется.
