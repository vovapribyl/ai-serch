# План-контракт поправки `ART-04` TO-BE v0.2

> [ART-00](../00-source-and-decision-register.md) · [ART-01](../01-vision-and-scope.md) · [ART-02](../02-stakeholders-and-glossary.md) · [ART-04](../04-to-be.md) · [Текущий контекст](../current-context.md)

| Поле | Содержание |
|---|---|
| Исполнитель | Codex |
| Цель | Применить утверждённые `DEC-038`–`DEC-040` к TO-BE: два сценария, минимальный вход, повторный маршрут `UNCERTAIN`, граница сохранения и человеческого решения. |
| Нормативные входы | `ART-00` v1.2: `DEC-038`–`DEC-040`, `GAP-006`; `ART-01` v0.7, `APPROVED_BY_OWNER`; `ART-02` v0.4, `REVIEWED_FOR_DEPENDENT_WORK`; `ART-04` v0.1 `DRAFT`. |
| Запрещённые выводы | Не выбирать источник истины, схему данных, срок хранения, интерфейс, модель, БД, API или архитектуру; не разрешать автосохранение неразрешённого `UNCERTAIN`, auto write-back или автоматический выбор при конфликтной истории; не менять классы поиска или возвращать `ANALOG`. |
| Ожидаемый результат | `ART-04` v0.2 с трассируемым TO-BE: `CHECK_ONLY`, `ADD_FOR_REVIEW`, обязательная фотография, текст как опциональное дополнение, повторный `UNCERTAIN`, условия сохранения и роль ЛПР. |
| Самопроверка | Сверить каждый сценарий с `DEC-038`–`DEC-040`, сохранить `GAP-006`, проверить отсутствие новых локальных ID/технических решений, Mermaid, таблицы и ссылки; после этого провести независимое read-only review. |

Контракт составлен исполнителем для полного маршрута. По указанию владельца текущего цикла на согласование выносится именно `ART-04` после независимой проверки.
