# План-контракт: граница ассортимента и причина отказа

> [`ART-01`](../01-vision-and-scope.md) · [`ART-04`](../04-to-be.md) · [`ART-05`](../05-business-rules.md) · [`ART-06`](../06-user-scenarios-and-functional-requirements.md) · [Реестр решений](../registers/decisions.md)

| Поле | Значение |
|---|---|
| Режим | `FULL` |
| Основание | Решения владельца в текущей беседе от 2026-08-28; `SRC-041`, `DEC-052` |
| Изменяемая граница | Статусы карточки фиксируют решение руководителя, но продукт не вводит товар в ассортимент фактически. Причина отказа необязательна; при её отсутствии продукт показывает установленную заглушку. |
| Не входит | Закупка, создание товарной позиции, публикация, изменение фактического ассортимента, UI, API, модель данных, НФТ и справочник причин. |
| Ожидаемый результат | Согласованные `ART-01` v1.0, `ART-04` v0.6, `ART-05` v0.3, `ART-06` v0.3 и маршрутизаторы без противоречий. |
| Самопроверка | Проверить границы бизнес-правил и функций, ссылки, ID, таблицы, статусы, конфликтные маркеры и `git diff --check`. |
| Независимый review | Один read-only reviewer после самопроверки; повторное review обязательно после `Critical` или `Major`. |

Первичное review зафиксировало 0 `Critical`, 1 `Major`, 3 `Minor`; после исправлений повторное независимое review завершено `PASS`, 0 `Critical`, 0 `Major`, 0 `Minor`. Следующий gate — явное утверждение владельца.
