## Границы

В работу входят постоянный `product_id`, номер строки как локатор снимка, XLSX как формат снимка, одно основное встроенное фото, необязательная исходная ссылка и проверки качества данных.

В работу не входят пользовательский экран загрузки, новая продуктовая роль, двусторонний обмен с Google Sheets, автоматическое обновление, предельный размер файла, СУБД, API и механизм обработки файла.

## Запрещённые выводы

- Не считать структурную проверку одного XLSX подтверждением производительности на размере 700 МБ.
- Не объявлять команду аналитиков владельцем данных: подтверждено только её назначение `product_id`.
- Не переносить служебную загрузку во взаимодействие роли `CHECK`.
- Не подменять второе изображение альтернативным поисковым фото в MVP.

## Ожидаемый результат и самопроверка

Исполнитель переводит `ART-07` из `DRAFT_STUB` в `DRAFT`, обновляет только связанные реестры, индексы и контекст. Перед review проверяются контракт артефакта, трассировка `SRC`/`DEC`/`GAP`, границы MVP и MVP 1.1, ссылки, уникальность ID, Markdown-таблицы, конфликтные маркеры и `git diff --check`.
