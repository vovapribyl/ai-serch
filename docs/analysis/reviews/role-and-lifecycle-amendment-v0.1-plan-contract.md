# План-контракт поправки ролей и жизненного цикла товара

> [ART-00](../00-source-and-decision-register.md) · [ART-01](../01-vision-and-scope.md) · [ART-02](../02-stakeholders-and-glossary.md) · [ART-03](../03-as-is.md) · [ART-04](../04-to-be.md)

| Поле | Содержание |
|---|---|
| Исполнитель | Codex |
| Цель | Закрепить решения владельца о должностях и ролях, уточнить обратный AS-IS-сценарий и описать жизненный цикл записи товара после поиска. |
| Нормативный вход | `SRC-034`: решения владельца в текущей беседе от 2026-08-26; `ART-00` v1.3; действующие `DEC-001`, `DEC-028`–`DEC-032`, `DEC-039`–`DEC-041`. |
| Изменяемые артефакты | `ART-00`, `ART-01`–`ART-04`, текущий контекст и статус проекта. Для `ART-04` применяется редактура `humanizer-ru` в техническом жанре: термины, статусы, ID, таблицы и Mermaid сохраняются. |
| Запрещённые выводы | Не выбирать технологическую БД, API, UI, модель данных, критерии пригодности фотографии, авторизацию, полный набор вспомогательных полей, правила сопоставления `SAME_PRODUCT`/`VARIANT` и автоматические переходы статусов. Не переносить поставщика в операционный процесс. |
| Ожидаемый результат | Поиск возвращает только результат и найденные статусы; `SUBMIT_FOR_REVIEW` создаёт запись со статусом `ADD_FOR_REVIEW`; дальнейшие жизненные статусы назначает руководитель ассортимента вручную. |
| Самопроверка | Проверить разделение AS-IS и TO-BE, отсутствие коллизии «сценарий/статус», неизменность осей результата, ссылки `SRC-*`/`DEC-*`/`GAP-*`, Mermaid и Markdown-таблицы; выполнить `git diff --check` и read-only review. |

Контракт составлен исполнителем для полного маршрута. После независимого review пакет будет передан владельцу на явное утверждение; до него новые редакции не считаются утверждёнными.
