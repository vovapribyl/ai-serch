# План-контракт: однократная загрузка рабочего корпуса MVP

| Поле | Значение |
|---|---|
| Режим | `FULL`: изменяются owner decision, scope и текущий gate |
| Вход | `SRC-052`, решение владельца от 2026-09-01 |
| Цель | Ограничить MVP однократной загрузкой уже переданного рабочего `SRC-045` и прекратить развитие функции перезагрузки корпуса |
| В scope | `ART-00`, `ART-06`–`ART-10`, план MVP, Gate 2 runbook/handoff, маршрутизирующие статусы и проектное правило явного запуска `sa-infostyle` |
| Вне scope | Удаление уже написанного кода, фактическая загрузка ограниченного файла, Gate 3, MVP 1.1 и изменение правил доступа к данным |
| Самопроверка | Ссылки, ID, статусы, конфликтные формулировки о замене/перезагрузке, Markdown и `git diff --check` |
| Независимый review | Один read-only reviewer; повторное review после `Critical` или `Major` |
| Owner gate | Проверенная редакция требует отдельного явного утверждения владельца |

## Ожидаемый результат

- MVP использует один рабочий XLSX `SRC-045`, уже переданный владельцем.
- Допустим повтор технической попытки только до успешного завершения первоначальной загрузки того же файла.
- Регулярная, пользовательская или служебная замена корпуса новым снимком не входит в MVP.
- Уже реализованный механизм версий и восстановления может остаться в коде, но не является условием Gate 2 и не развивается дальше в текущем цикле.
- Gate 2 закрывается доказательством первоначальной загрузки и пригодности корпуса для Gate 3, а не доказательством безопасной перезагрузки.
