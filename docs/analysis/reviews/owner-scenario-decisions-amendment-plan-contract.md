# План-контракт закрепления решений владельца о сценариях использования

> [ART-00](../00-source-and-decision-register.md) · [ART-01](../01-vision-and-scope.md) · [ART-02](../02-stakeholders-and-glossary.md) · [ART-04](../04-to-be.md) · [Текущий контекст](../current-context.md)

| Поле | Содержание |
|---|---|
| Исполнитель | Codex |
| Цель | Закрепить ответы владельца от 2026-08-18 о двух сценариях использования, минимальном входе, маршруте `UNCERTAIN`, отсутствии сохранения без результата, фиксации человеческого решения и конфликтной истории. |
| Нормативные входы | Утверждённые `ART-00` v1.1, `ART-01` v0.6, `ART-02` v0.3, `ART-03` v0.2; `ART-04` v0.1 `DRAFT`; ответ владельца в текущей беседе. |
| Область | Сначала `ART-00` v1.2: первичный источник и решения; после его независимой проверки — согласованные поправки Vision & Scope, стейкхолдеров и TO-BE. |
| Запрещённые выводы | Не выбирать реализацию, UI, API, БД, авторизацию или права доступа; не считать результат поиска бизнес-решением; не назначать должность ЛПР; не раскрывать ограниченные исходные данные; не считать точный источник фиксации решения установленным. |
| Ожидаемый результат | Трассируемые решения владельца и последовательные редакции артефактов: сценарий `CHECK_ONLY`, сценарий `ADD_FOR_REVIEW`, обязательная фотография, повторный поиск при `UNCERTAIN`, отсутствие сохранения без результата, граница write-back и разрешение конфликтной истории. |
| Самопроверка | Проверить отсутствие конфликта с `DEC-001`, `DEC-025`–`DEC-031`, `DEC-034`–`DEC-037`; разделение ролей и сценариев; сохранение `UNKNOWN` о точном источнике решения; Markdown, ссылки и отсутствие новых небазовых ID. |

Исполнитель создаёт этот контракт в полном маршруте `DEC-035`/`DEC-037`; отдельный агент-планировщик не используется.
