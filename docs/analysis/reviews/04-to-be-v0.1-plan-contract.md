# План-контракт создания `ART-04` TO-BE v0.1

> [ART-00](../00-source-and-decision-register.md) · [ART-01](../01-vision-and-scope.md) · [ART-02](../02-stakeholders-and-glossary.md) · [ART-03](../03-as-is.md) · [Текущий контекст](../current-context.md)

| Поле | Содержание |
|---|---|
| Исполнитель | Codex |
| Цель | Описать целевой бизнес-процесс внутреннего инструмента поддержки решения: вход товарного предложения, поиск по корпусу, выдача кандидатов и истории, человеческое бизнес-решение и известные точки контроля. |
| Нормативные входы | `ART-00` v1.1, `APPROVED_BY_OWNER`: `DEC-001`, `DEC-003`, `DEC-025`–`DEC-031`, `DEC-034`–`DEC-037`, `GAP-006`; `ART-01` v0.6; `ART-02` v0.3; `ART-03` v0.2. |
| Запрещённые выводы | Не выбирать модель, БД, API, UI, интеграцию или архитектуру; не превращать AS-IS в TO-BE; не назначать должности или полномочия; не устанавливать обязательный write-back, правила обработки `UNCERTAIN` или точные исключения без решения владельца; не отождествлять результат поиска с бизнес-решением. |
| Ожидаемый результат | `ART-04` v0.1 в статусе `DRAFT` с минимальным целевым потоком, ролями `Инициатор товара` и `ЛПР по товару`, точками контроля, границей ответственности системы и компактно выделенными решениями `GAP-006`. |
| Самопроверка | Проверить согласованность с двумя осями результата и исключением `ANALOG`; отсутствие технических решений и новых требований; разделение принятых положений, `UNKNOWN` и `DECISION_REQUIRED`; отсутствие новых небазовых ID; ссылки, таблицы и Mermaid. |

Этот контракт составлен исполнителем для полного маршрута `DEC-035`/`DEC-037`; отдельный агент-планировщик не используется.
