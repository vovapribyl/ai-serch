# План-контракт оптимизации проектного контекста и процесса

> [`ART-00`](../00-source-and-decision-register.md) · [Проектные инструкции](../../../AGENTS.md) · [Governance](../governance.md)

| Поле | Значение |
|---|---|
| Цель | Сократить фиксированный контекст, число повторных чтений и необязательных агентных проходов без ослабления доказательности значимых аналитических решений |
| Граница | `AGENTS.md`, структура `ART-00`, маршруты чтения, правила `FAST_PATH / STANDARD / FULL`, выбор моделей, обращение с крупными источниками и короткие навигационные документы |
| Нормативные входы | `SRC-023`, `SRC-025`, `SRC-026`, `DEC-035`–`DEC-037`; ратифицированный владельцем пакет оптимизации от 2026-08-19 (`SRC-032`, `DEC-041`) |
| Запрещённые выводы | Не менять продуктовые решения, классы результата, роли, scope или статус `ART-04`; не менять глобальный `~/.codex/config.toml`; не удалять и не перенумеровывать существующие ID |
| Ожидаемый результат | Короткий `AGENTS.md`; единый `governance.md`; `ART-00` как пакет с коротким индексом и выборочно читаемыми реестрами; сокращённые маршрутизирующие документы |
| Самопроверка | Сохранение всех `SRC-*`/`DEC-*`/`GAP-*` и legacy-ID; корректные относительные ссылки и Markdown-таблицы; отсутствие конфликтных маркеров; `git diff --check`; отсутствие предметных изменений |
| Независимая проверка | Один read-only ревьюер; повторное ревью только после `Critical` или `Major` |
| Owner gate | Проверенная редакция `ART-00` v1.3 и governance-пакет получают `PENDING_OWNER_APPROVAL`; `APPROVED_BY_OWNER` возможен только после отдельного подтверждения владельца |
