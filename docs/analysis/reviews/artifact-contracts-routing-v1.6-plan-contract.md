# План-контракт: контракты артефактов и маршрутизация содержания

> [Контракты артефактов](../artifact-contracts.md) · [Governance](../governance.md) · [`ART-00`](../00-source-and-decision-register.md) · [Каталог review](README.md)

| Поле | Значение |
|---|---|
| Режим | `FULL` |
| Основание | Решение владельца `SRC-037`, `DEC-047`–`DEC-048`; изменение нормативных границ документов и gate |
| Исполнитель | Codex |
| Независимый reviewer | Один read-only reviewer после самопроверки |
| Граница | Контракты `ART-00`–`ART-10`, правила маршрутизации, аудит `ART-00`–`ART-05`, переработка `ART-05`, создание `ART-06` `DRAFT_STUB`, синхронизация маршрутизаторов и реестров |
| Не входит | Полноценная разработка `ART-06`–`ART-10`, архитектура, реализация продукта, новые предметные решения |

## Ожидаемый результат

- Для каждого `ART-*` определены назначение, обязательное, допустимое и запрещённое содержание, входы и выходы.
- Материал вне контракта переносится в канонический целевой артефакт без изменения смысла, происхождения и статуса утверждения.
- Если целевого документа ещё нет, создаётся минимальный `DRAFT_STUB`; он не считается готовым или утверждённым артефактом.
- Бизнес-требования остаются в `ART-01`, бизнес-правила — в `ART-05`, пользовательские сценарии и функциональные требования — в `ART-06`.
- Каждое содержательное положение прежнего `ART-05` v0.1 сохраняется в `ART-05` v0.2, `ART-06` v0.1 `DRAFT_STUB` либо в истории переработки.

## Самопроверка исполнителя

- Провести аудит `ART-00`–`ART-05` по утверждённым владельцем границам.
- Зафиксировать таблицу переноса `ART-05 → ART-05 / ART-06` и проверить полноту строк.
- Не менять предметный смысл `SRC-036`, `DEC-044`–`DEC-046`.
- Не превращать `DRAFT_STUB` в готовый зависимый артефакт.
- Проверить локальные ссылки, статусы, версии, действующие ID, конфликтные маркеры, Markdown-таблицы и `git diff --check`.

## Критерии независимого review

- Контракты не допускают смешения бизнес-требований, бизнес-правил и функциональных требований.
- Правила маршрутизации защищают от потери, скрытого дублирования и повышения статуса материала.
- Аудит `ART-00`–`ART-05` применяет контракты последовательно.
- Перенос из `ART-05` полон и не меняет решения владельца.
- `ART-06` остаётся честным `DRAFT_STUB`, а маршрутизаторы не представляют его готовым документом.
