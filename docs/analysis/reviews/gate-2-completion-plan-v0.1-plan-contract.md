# План-контракт: исполнимый план завершения Gate 2

| Поле | Значение |
|---|---|
| Режим | `FULL`: новый план закрытия контрольной точки Gate 2 |
| Вход | `SRC-053`; утверждённая поправка `DEC-059`; запрос владельца подготовить handoff для модели Terra в другом чате |
| Цель | Создать отдельный пошаговый документ, достаточный для безопасной первоначальной загрузки рабочего корпуса, фиксации свидетельства, review и отдельного owner gate результата |
| Исполнитель следующего цикла | `gpt-5.6-terra`, reasoning `medium`, если пользователь не задаст другой режим |
| В scope | Предпроверки, изолированный PostgreSQL-контур, первоначальная загрузка `SRC-054`, восстановление только той же операции, агрегированное свидетельство, независимое review и owner gate результата |
| Вне scope | Плановая перезагрузка, Gate 3, изменение бизнес-требований, публикация restricted data, merge/push/commit без отдельного запроса |
| Самопроверка | Команды сопоставлены с текущим кодом; пути, checksum, exit codes, stop conditions, статусы и локальные ссылки проверены; `git diff --check` |
| Независимый review | Один read-only reviewer; после `Critical` или `Major` повторное review обязательно |
| Результат | `docs/gate-2-completion-plan.md`, готовый для исполнения в отдельном чате после успешного review |
