## Major

### M-01 — Применимость `VARIANT` и `UNRELATED`

`FR-005` требовал показывать `VARIANT` и `UNRELATED` для любых отличающихся кандидатов. Это расширяло `ART-05`, §5: детальные правила действуют только для «Накладных ногтей», вне ногтевого поднабора допустимы только `NEW` и `UNCERTAIN`, а для остальных категорий остаётся `GAP-003`.

Исправление: ограничить требование категориями с утверждёнными правилами и явно сохранить границы `ART-05`, §5 / `GAP-003`.

### M-02 — Последовательность quality gate

План-контракт и история фиксировали завершённую авторскую самопроверку, тогда как часть паспортов и маршрутизаторов ещё ставила её перед независимым review. В `ART-04` исторический `PASS` выглядел как результат текущей версии.

Исправление: синхронизировать последовательность `SELF_CHECK_COMPLETED → independent review → исправления → повторное review → owner gate` и явно отделить исторические проверки от текущего пакета.
