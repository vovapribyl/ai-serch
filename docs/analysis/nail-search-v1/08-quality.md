## Состояние требований

Пакет сохраняет действующие ограничения безопасности и локального доступа. Новые количественные NFR не утверждены.

| Показатель | Состояние | Кто и когда определяет |
|---|---|---|
| Время подготовки каталога | `UNKNOWN` | Исполнитель оценивает после согласования контура; владелец принимает предел до запуска |
| Время ответа по числу фото и ногтей | `UNKNOWN` | Исполнитель предлагает метод измерения; владелец выбирает целевой предел |
| Объём хранения | `UNKNOWN` | После аудита числа фото/областей и выбора моделей |
| Допустимые форматы, размер и число фото | Существующие ограничения Gate 4 сохраняются; изменение не согласовано | Подтвердить совместимость до реализации |
| Допустимая деградация при ошибке модели | `UNKNOWN` | Владелец выбирает после предложения исполнителя |

Ответы владельца 2026-10-07: тот же товар, если он есть в корпусе, обязан попасть в top-10 на оцениваемых примерах; top-3 желателен. Это OWNER_DECISION / VERIFIED как критерий ожидания, не измеренный Recall@10 и не гарантия любого будущего запроса. Размер фото на Mac контролирует владелец: не больше ранее тестировавшихся, точное число UNKNOWN. Existing upload limits сохраняются. Отдельная программа стресс-тестов и универсальные количественные NFR не утверждены; finite технические transport/execution parameters готовятся отдельно.

Метод ручной проверки находится в [ART-09](09-acceptance.md), оставшиеся вопросы — [ART-10](10-open-items.md).
