# Термины и ответственность

| Поле | Значение |
|---|---|
| Артефакт | Дополнение к `ART-02`; не новая версия утверждённого базового документа |
| Версия / дата | v0.2 / 2026-10-04 |
| Статус | `DRAFT`; пакет изменения, не разрешение реализации |
| Владелец и утверждающий | Владелец проекта |
| Входы и происхождение | [Индекс и свидетельства диалога](README.md); утверждённые базовые ART и Gate 3/4 |
| Следующий gate | Независимое review → утверждение документации владельцем; технические открытые решения отдельно |

Назначение: материал уровня `ART-02` в границе поиска по отдельным ногтям. Канонические детали других уровней находятся в соседних документах, а не в этом дополнении.

| Термин | Значение |
|---|---|
| Модуль выделения ногтей | Человекочитаемое название существующего эксперимента `Candidate I`; отдельный от поиска модуль, предлагаемый к подключению. Название принято для документации, новых возможностей не означает |
| Фильтр масок | Эксперимент `Candidate J`, поставлен на паузу; в первую итерацию поиска не входит |
| Товар | Единица итоговой выдачи; одно или несколько каталожных фото относятся к одной записи товара |
| Ракурс | Одно исходное фото; координаты ногтей между фото не обязаны совпадать |
| Выделенная область | Detection/mask Модуль выделения ногтей, считаемая ногтем для обработки; истинность этого предположения не гарантирована |
| Обрезка ногтя | Производное изображение одной выделенной области; способ удаления фона ещё не выбран |
| Пара фото | Один ракурс запроса и один ракурс каталожного товара |
| Сопоставление | Набор пар областей внутри пары фото; повторное использование каталожной области запрещено |
| Оценка сходства | Величина для ранжирования; не вероятность тождества и не подтверждение `SAME_PRODUCT` |
| Лучшая пара | Пара фото с наибольшей определённой оценкой для данного товара; формула пока открыта |

Владелец проекта выбирает правила и критерии качества. `CHECK` загружает фото и проверяет кандидатов. Исполнитель проектирует и реализует только после соответствующего утверждения; reviewer проверяет read-only.

## История и проверка

v0.1: создано из обсуждения 2026-10-04. Самопроверка и независимое review фиксируются в индексе пакета. Реализация и runtime-проверки не выполнялись.

Уточнение v0.2: русские названия введены по просьбе владельца; технические идентификаторы сохранены в этом глоссарии для трассировки.
