## Проверки выбранного поведения

Проверки ниже — проект критериев, не отчёт исполнения. Все имеют статус `NOT_RUN`.

| Проверяемое поведение ART-06 | Пример проверки | Ожидаемое свидетельство |
|---|---|---|
| Отдельные ногти, связь с товаром | Несколько областей одного фото и несколько фото товара | Отдельные обрезки/эмбеддинги, один товар в выдаче; соответствие ART-07 |
| Равный вес и участие всех областей | Добавить слабое соответствие к хорошим | При выбранной формуле слабое соответствие учтено; ни один ноготь не удалён фильтром |
| Нет повторного использования | Пять областей запроса, четыре каталога | Максимум четыре пары, одна без соответствия; копий нет |
| Нет штрафа за лишние области каталога | Добавить неиспользованную область каталога | При прочих равных оценка не снижается |
| Лучший ракурс | Добавить удачный ракурс после слабого | Пересчитанная выдача использует лучшую пару, без ухудшения за сохранённое слабое фото |
| Нет бонуса за повторы | Добавить точную копию фото | Оценка не повышается от числа одинаковых ракурсов |
| Отсутствие областей | Одно пустое фото среди успешных; затем все пустые | Пояснение пропуска; при всех пустых просьба о другом фото, резервный поиск отсутствует |

Выбрано описанное поведение оценки и ошибок; конкретные технические contracts и numeric tie/precision детали находятся в HLD/LLD. Проверки таблицы NOT_RUN, полнота технической приёмки ещё не подтверждена.

## Проверка бизнес-эффекта

Владелец 2026-10-07 указал: «Обязательно попадает в 10, желательно в тройку», «Я сам оценю качество после тестирования поиска»; отсутствие товара выбирает после проверки кандидатов. OWNER_DECISION / VERIFIED как критерий и способ оценки, не факт качества.

Проверочный запрос — обычный поиск с известным правильным ответом: новый снимок товара, присутствующего в корпусе. На выбранных владельцем примерах отсутствие этого товара в top-10 является дефектом; top-3 фиксируется как желаемый результат, не обязательный отдельный порог. Размер и состав примеров UNKNOWN. Успех на них не гарантирует успех на любом будущем фото. Если присутствующий товар не подготовлен/исключён из representation, это не отменяет критерий владельца: coverage ограничение предъявляется отдельно, не превращается в правильный NEW.

Владелец оценивает новые выдачи вручную. Обязательный сравнительный прогон старого и нового поиска этой итерацией не принят. Классификаторы ракурса/фона/частичности и специальная сложная выборка не требуются: вариации обычных фото можно наблюдать без новых компонентов. NEW — ручное решение, не автоматическая классификация или порог сходства.

Данные, model calls, подготовка каталога и выборка остаются отдельно разрешаемыми операциями; старые restricted claims/evaluation не переиспользуются. Техническая корректность не отменяет прежний отрицательный Gate 4 и не доказывает улучшение.
