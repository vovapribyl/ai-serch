## Граница AS-IS

Этот документ описывает существующий локальный продукт Gate 3/4 и отдельно существующий Модуль выделения ногтей. Исходный внешний бизнес-процесс рассмотрения товаров описан в [базовом ART-03](../03-as-is.md); здесь он не переписывается. AS-IS ниже реконструирован по коду и сохранённым свидетельствам, а не наблюдению запущенного сервиса.

## Подготовка каталога в существующем поиске

| Шаг | Участник | Вход → действие → результат | Основание |
|---|---|---|---|
| Первоначальная загрузка | Исполнитель, загрузчик | Рабочий снимок → проверка и импорт → одна активная версия, 674 записи и основных фото | Gate 2/3; ссылки выше |
| Индексация | Поисковый контур | Целое основное фото каждой записи → три модели → по одному эмбеддингу записи на модель | [index_active_corpus](../../../../../../.codex/worktrees/1eaf/Ai/src/product_search/search/embedding_index.py), Gate 3 |
| Контроль | Исполнитель, владелец | Проверки → evidence и утверждение Gate 3 → подготовленный поисковый корпус | Gate 3 owner approval |

Действующий indexer читает `product_records.image_path`, а не коллекцию отдельных ногтей. Число 2022 относится к существующим эмбеддингам целых фото. Это не ожидаемый объём будущего индекса.

## Поиск и работа пользователя

| Шаг | Участник | Действие и результат | Основание |
|---|---|---|---|
| Загрузка | Пользователь `CHECK`, интерфейс | Пользователь передаёт фото; продукт проверяет формат и лимиты | Gate 4, функциональный контур |
| Поиск одного ракурса | Поисковый контур | Целое фото передаётся каждой модели; результаты точного поиска объединяются RRF | `FusedSearchService.execute` |
| Показ | Интерфейс, пользователь | До 10 товаров-кандидатов; пользователь проверяет совпадение | Gate 3/4 |
| Дополнительные ракурсы | Пользователь, поисковый контур | Добавление фото и повторный поиск по накопленным ракурсам; существующий `execute_many` использует лучшие ранги по моделям и RRF | Gate 4 v3; `FusedSearchService.execute_many` |
| Оценка | Пользователь | Покандидатная ручная разметка и итог запроса сохраняются по действующему сценарию | Gate 4; ранг сам не подтверждает тождество |

Существующая агрегация ракурсов по рангам моделей не равна проектируемой оценке лучшей пары фото по сопоставлению ногтей.

## Отдельно существующий Модуль выделения ногтей

По [handoff](../../../../../../.codex/worktrees/1eaf/Ai/docs/project-resume-20261004.md) модуль уже выдавал выделенные области и маски в экспериментальном контуре. Владелец считает результат достаточным для следующего этапа поиска. В сохранённой оценке отмечены лишние объекты, срезы ногтя и попадание кожи; это ограничения результата, не перечень автоматически исключаемых областей.

Модуль не вызывается существующим поиском. Каталожные эмбеддинги отдельных ногтей, сопоставление их наборов и интеграция с выдачей пока не реализованы. Исторический `REWORK` не отменён. Фильтр масок находится на паузе и не является частью текущего поиска.

## Проблема и неизвестные

Владелец не принял качество поиска Gate 4. Влияние рук, фона и расположения на выдачу — гипотеза, а не установленная причина отрицательного результата. Не проверены: текущий запущенный сервис, доступность дополнительных каталожных ракурсов и эффект подключения выделения.

## История и проверка

v0.1: первоначальная запись контекста. v0.2: по замечанию владельца раскрыты процесс текущего поиска, подготовка каталога и отдельно существующий модуль; новая функциональность не приписана AS-IS. Проверки редакции фиксируются в индексе пакета.
