## Граница целевого процесса

Модуль выделения ногтей подключается к подготовке каталога и обработке фото запроса. Пользователь получает список товаров, а не набор найденных ногтей. Внешнее рассмотрение, роли, ручное подтверждение тождества и правила результатов остаются в [базовом ART-04](../04-to-be.md). Этот документ раскрывает только изменение этапа поиска.

## Подготовка каталога до пользовательского поиска

| Шаг | Ответственный | Вход и действие | Результат / контроль |
|---|---|---|---|
| Определить доступные фото | Исполнитель подготовки | Проверить фото подготовленного корпуса и их принадлежность товарам | Полнота входа известна; получение новых внешних фото отдельно не разрешено |
| Выделить ногти | Модуль выделения ногтей | Обработать все доступные каталожные ракурсы | Для каждого фото доступны области либо явно установлен исход обработки |
| Подготовить поиск | Продукт | Подготовить отдельные изображения ногтей и поисковые представления с привязкой к товару и фото | Каталог для сопоставления; детали в ART-06/07 |
| Проверить готовность | Исполнитель, владелец | Проверить охват каталога и результаты обработки | Отчёт о готовности и исключениях; активация после отдельного решения |

Если у товара ни на одном фото нет выделенных областей или обработка завершилась ошибкой, порядок действий ещё не определён. Такие товары нельзя молча считать успешно подготовленными. Данные старого поиска сохраняются для сравнения; способ активации и отката открыт.

## Пользовательский поиск

| Шаг | Ответственный | Действие | Результат / ветвление |
|---|---|---|---|
| Загрузить фото | `CHECK` | Передать одно или несколько фото одного товара | Вход запроса в пределах действующих ограничений |
| Проверить загрузку | Продукт | Выполнить существующие проверки входных файлов | Допущенные фото; технические отказы отдельно от отсутствия ногтей |
| Выделить ногти | Модуль выделения ногтей | Обработать фото запроса | Области для сопоставления; фото без областей отмечены |
| Проверить наличие областей | Продукт | Определить, есть ли фото с выделенными областями | Если нет — просьба о другом фото; если есть — поиск по ним |
| Сравнить с каталогом | Продукт | Сопоставить ногти отдельных пар ракурсов запроса и товара | Оценка товара с опорой на лучшую пару; формула открыта |
| Показать кандидатов | Продукт, `CHECK` | Показать ранжированные товары и пояснения пропущенных фото | Пользователь проверяет предполагаемые совпадения; рейтинг не устанавливает тождество |
| Добавить ракурс | `CHECK`, продукт | Добавить фото того же товара и пересчитать общую выдачу | Удачное последующее фото может улучшить результат; повторы не дают бонуса количеством |

Подтверждённое отсутствие областей на одном фото не останавливает обработку других. Если областей нет на всех фото, резервный поиск по целым изображениям не выполняется. Политика технических ошибок модуля пока открыта.

## Переход AS-IS → TO-BE

| Аспект | AS-IS | TO-BE |
|---|---|---|
| Каталог | Основное целое фото записи | Все доступные ракурсы товара с выделенными ногтями |
| Запрос | Эмбеддинг целого фото | Отдельные представления выделенных ногтей |
| Участие модуля | Эксперимент отдельно от поиска | Подготовка каталога и обработка запроса |
| Сопоставление | Сходство целых изображений | Сопоставление нескольких ногтей внутри пары фото |
| Ракурсы | Лучшие ранги по моделям и RRF в существующем v3 | Лучшая пара ракурсов по новой оценке; объединение моделей ещё выбирается |
| Выход | Ранжированные товары, ручная проверка | Те же единицы выдачи и роль человека; целевой приоритет того же товара |

## Точки решения и границы

Процесс описывает выбранное направление, а не готовую архитектуру: единая программа, отдельный сервис или worker здесь не выбираются. Правила сравнения — [ART-06](06-functions.md), связи данных — [ART-07](07-data.md), критерии — [ART-09](09-acceptance.md), открытые решения — [ART-10](10-open-items.md).

Проверка пригодности масок, выравнивание, исправление геометрии, дорисовка и Фильтр масок отложены. Все технически обрабатываемые области участвуют с согласованным весом. Процесс не утверждает формулу, пороги, улучшение качества или разрешение запускать обработку корпуса.
