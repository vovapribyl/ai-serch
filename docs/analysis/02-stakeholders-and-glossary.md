## 1. Назначение и границы

Этот артефакт фиксирует согласованные должности, функциональные роли и рабочие значения терминов. Он не выбирает авторизацию, модель данных, владельца данных или правила реализации.

`ANALOG` явно исключён из границы продукта и не является классом результата (`DEC-030`). Аналитик не является стейкхолдером или операционной ролью продукта; его участие в benchmark-разметке является проектной функцией QA (`DEC-027`, `DEC-033`).

## 3. Глоссарий и пограничные примеры

Согласно `DEC-031`, используются две разные оси: итог запроса относительно доступного корпуса — `NEW` / `SAME_PRODUCT` / `UNCERTAIN`; отношение запроса к конкретному отличающемуся кандидату — `VARIANT` / `UNRELATED`. Для подтверждённого `SAME_PRODUCT` вторая ось имеет значение `N/A`.

| Термин | Рабочее значение | Пограничный пример или ограничение | Основание |
|---|---|---|---|
| `NEW` | Итог запроса: тот же товар в доступном корпусе не найден. | Сам по себе не создаёт запись. Пользователь может вручную вне продукта внести товар в Google Sheets для рассмотрения. | `DEC-031`, `DEC-053`, `ART-05` §§3–4 |
| `SAME_PRODUCT` | Итог запроса: одинаковы конструкция, назначение и существенные характеристики; различия продавца, карточки, фотографии, упаковки или нанесённого бренда этому не препятствуют. | Изменение состава, геометрии или функции означает другой товар. Точная граница «существенной характеристики» по категориям остаётся `UNKNOWN`. | `DEC-028`, `GAP-003`, `VQ-002` |
| `UNCERTAIN` | Итог запроса: доступных данных недостаточно, чтобы подтвердить или исключить тот же товар. | Это не значение отношения к конкретному кандидату. Пользователь добавляет фотографии и/или доступные текстовые метаданные, затем повторяет поиск; неразрешённый результат не сохраняется. | `DEC-031`, `DEC-039`; правило — `ART-05` §4, поведение — `ART-06` §2 |
| `CHECK` | Единственный сценарий и роль MVP: сверка товара с подготовленным корпусом и просмотр доступных кандидатов, статусов и истории. | Фотография обязательна; текстовые метаданные опциональны. Запись не создаётся. | `DEC-053`; правило — `ART-05` §§2–4, поведение — `ART-06` §2 |
| ручное внесение на рассмотрение | Внешний шаг после `NEW`: пользователь вручную вносит товар в Google Sheets. | Не является действием продукта и не создаёт запись автоматически. | `DEC-053`; `ART-04` §3 |
| `APPROVED_FOR_ASSORTMENT` | Жизненный статус внешней записи: зафиксировано положительное решение по товару. | MVP может только показать доступное значение. | `DEC-052`, `DEC-053` |
| `REJECTED_FOR_ASSORTMENT` | Жизненный статус внешней записи: зафиксировано отрицательное решение по товару. | Причина может отсутствовать; MVP показывает установленную заглушку. | `DEC-052`, `DEC-053` |
| `PHASE_OUT` | Жизненный статус внешней записи: товар ещё продаётся, но новые заказы не планируются. | Правила изменения не входят в MVP. | `DEC-053` |
| `OUT_OF_ASSORTMENT` | Жизненный статус внешней записи: товар выведен из ассортимента после цикла продаж. | Правила изменения не входят в MVP. | `DEC-053` |
| `VARIANT` | Отношение к конкретному отличающемуся кандидату: та же базовая модель, у которой отличается ровно одно свойство. | Один и тот же рисунок с другим цветом элемента может быть вариантом; точные границы одного «свойства» остаются `UNKNOWN`. Решение по одному варианту не переносится автоматически. | `DEC-029`, `GAP-003`, `VQ-002` |
| `UNRELATED` | Отношение к конкретному отличающемуся кандидату: другой товар. | Похожая по назначению или форме, но иная модель также является другим товаром; отдельного класса `ANALOG` нет. | `DEC-030`, `DEC-031` |
| `N/A` | Неприменимость второй оси для подтверждённого `SAME_PRODUCT`. | Не является самостоятельным итогом запроса. | `DEC-031` |
| `ДУБЛИКАТ AS-IS` | Только повтор внешнего идентификатора, отмечаемый текущей таблицей в столбце H. | Не является синонимом `SAME_PRODUCT`; термин «дубликат» не используется без уточнения контекста. | `DEC-032` |
| другой товар | Конкретный отличающийся кандидат, отношение запроса к которому классифицировано как `UNRELATED`. | Изменение состава, геометрии или функции означает другой товар; похожая по назначению или форме, но иная модель также является другим товаром; иной принт считается другим товаром. | `DEC-028`, `DEC-029`, `DEC-030`, `DEC-031` |

Для «Накладных ногтей» `VARIANT` возможен только при одном отличии: близком оттенке, количестве или комплектации набора. Длина, дизайн/принт, форма, материал, технология производства, категория и несколько отличий означают `UNRELATED`. Для остальных категорий детальные правила ещё не определены (`DEC-053`, `GAP-003`).
