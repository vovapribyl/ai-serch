## Назначение

Этот документ позволяет воспроизвести технический каркас Gate 1 на чистой локальной машине. Он не разрешает импорт корпуса, загрузку фотографий или моделей.

## Локальная подготовка

Нужны Python 3.12, Docker Engine с Compose и доступ в интернет только для первоначального получения Python-пакетов и образа PostgreSQL. Рабочий каталог данных создаётся вне репозитория и доступен только текущей учётной записи.

```sh
python3.12 -m venv .venv
.venv/bin/python -m pip install -e '.[dev]'
mkdir -p /absolute/path/to/product-search-mvp-data
chmod 700 /absolute/path/to/product-search-mvp-data
cp .env.example /absolute/path/to/product-search-mvp.env
chmod 600 /absolute/path/to/product-search-mvp.env
```

В `/absolute/path/to/product-search-mvp.env` нужно заменить `MVP_POSTGRES_PASSWORD` на случайный секрет и указать созданный `MVP_DATA_DIR`. Файл с секретом не может находиться внутри репозитория.

Проверить технический каркас:

```sh
make test
make lint
make check-delivery
make db-up MVP_ENV_FILE=/absolute/path/to/product-search-mvp.env
make migrate MVP_ENV_FILE=/absolute/path/to/product-search-mvp.env
make run MVP_ENV_FILE=/absolute/path/to/product-search-mvp.env
```

После `make run` локальный экран доступен только по `http://127.0.0.1:8000/`. Маршрут `/health` отвечает `200`, когда PostgreSQL доступна, и `503` с понятным сообщением, когда база недоступна. Это ожидаемый статус при выключенном Docker Engine.

## Ограничения данных

- `MVP_DATA_DIR` обязан быть абсолютным путём вне репозитория; путь в репозитории блокирует запуск.
- У каталога не может быть доступа группы или других локальных пользователей; небезопасные права блокируют запуск.
- Временные query-файлы удаляются при успехе и исключении.
- В Git и поставке не допускаются корпус, изображения, отчёты и веса моделей; это проверяет `make check-delivery`.
