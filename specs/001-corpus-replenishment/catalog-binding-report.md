## Что реализовано

Поиск получил отдельный путь для снимков каталога. Он принимает
`SnapshotSearchRequest` и возвращает `SnapshotSearchResult` с descriptor снимка.
Снимок не выдаётся за прежний `representation_id`. Настройка
`catalog_backend=legacy|snapshot` выбирается явно; прежний путь остаётся
значением по умолчанию. Неверная настройка и запрос другого типа отклоняются.

`resolve_active` получает descriptor активного готового снимка. Затем запрос
использует только этот descriptor. `read_snapshot` проверяет сохранённый состав,
его хеш, готовность редакций, единый профиль и полноту областей и векторов.
Данные читаются потоком в прежнем порядке: товар, номер фото, номер области,
модели по `MODEL_DIMENSIONS`. В поток попадают только фото `OK`.

Смена активного указателя не меняет уже закреплённый запрос. Старый снимок
можно дочитать по его descriptor; автоматического перехода на новый нет.
Поток и SQL-ресурсы закрываются также при ошибке и при результате `NEED_MORE_PHOTOS`.

`VerifiedCatalogBinding` связывает descriptor, полный профиль embeddings,
проверенную runtime identity, query claim и бюджет solver. Профиль включает
версию crop, три модели, размерности, revisions, preprocessing и dtype.
Claim отдельно ограничивает допустимые снимки и конкретные хеши входных фото.

Адаптер сравнивает независимое наблюдение runtime с ожидаемыми метаданными через
существующий `RuntimeVerifier`. Дополнительно сверяются SHA runtime, кода,
модельного состава и claim, полный профиль наблюдения и профиль БД.
Ни название модели, ни один ID снимка не заменяют этих проверок.
Сбой наблюдения или несовпадение закрывают admission.

Общий расчёт ранжирования выделен внутри `NailSearchService` и используется
обоими путями. Matching, score_kind, выбор лучшей пары фото и порядок кандидатов
сохранены. Порт чтения принадлежит ядру; SQL и наблюдение runtime остаются
в инфраструктуре.

без адаптера, который подменял бы snapshot ID прежним representation ID.

в `test_nail_dependency_boundaries.py`. Остальные 78 записей baseline совпали.

manifest сохранён. [Список изменений и новых SHA](catalog-binding-baseline-changes.json).
Риск изменения общей логики покрыт legacy-регрессией и synthetic parity.

и HTTP-сервисы не запускались. Зависимости не устанавливались.

binding; она не утверждает новый эксплуатационный runtime или право использовать
реальные query inputs. Для них сохраняется отдельный пакет и gate 049–050.

ещё не подключены; backend существующего приложения не переключён.

вертикальный fake-сценарий. Recovery, ожидание и ручной retry остаются отдельными
незавершёнными пунктами. Полный suite и готовность всей функции не подтверждены.
