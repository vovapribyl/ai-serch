# Пакетная проверка пополнения корпуса

Дата: 2026-10-15. Статус: COMPLETED_WITH_LIMITATIONS. Маршрут STANDARD: исполнение существующих критериев, без новых нормативных требований.

Владелец прямо разрешил составлять планы и проводить проверки пакетом без промежуточных запросов разрешения. Это разрешение применяется к ограниченным тестовым контурам ниже и заменяет отдельные запросы допуска каждого их запуска. SHA каждого конкретного пакета всё равно фиксируется до исполнения; идентификаторы RESUME определяются только из реально сохранённого состояния. Неизвестные результаты не считаются принятыми.

Исполнение последовательное одним исполнителем. Применяются writing-plans/executing-plans; отдельный reviewer для STANDARD не создаётся по AGENTS. Изменения продуктового кода не планируются; при найденном дефекте его исправление проходит TDD отдельно от фиксации неуспешного прогона. Commit/push/merge не входят в работу.

## Общие ограничения

Один testDB одновременно, закреплённый PostgreSQL image,512MiB/1CPU/128PID/tmpfs256MiB/localhost и no pull/restart/host volumes. Synthetic native только собственные children/groups. RealML: не более5фото за START, одна тяжёлая стадия одновременно,1200с/package, RSS/MPS6GiB и encoder RSS5GiB, прежние HTTP/DB/TERM/KILL/cleanup и input/IPC/file limits. Каждый новый real контур максимум2520с, сохранённая DB не удерживается бессрочно.

Пакет не разрешает разрушительные аварии рабочей системы, установку dependencies, увеличение потолков, изменение модели или productioncutover. Ошибка шага сохраняется без автоматического повтора; зависимые шаги SKIPPED_DEPENDENCY, независимые продолжаются. При неподтверждённой own cleanup исполнение runtime прекращается; чужие ресурсы не трогаются. Отсутствующий эталон/вход фиксируется отдельно от запроса разрешения.
