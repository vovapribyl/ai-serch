# Повторная серия: остановка на локализации по RESOURCE_STOP

Дата: 2026-10-15. Статус: **EXECUTED / STOPPED_RESOURCE_STOP**.

Владелец разрешил оба пакета из [повторного предложения](sequential-batches-repeat-proposal.md). В партии A был отправлен один START; обработка остановилась по `RESOURCE_STOP` на локализации. B не запускалась, поскольку A не прошла критерии успешного завершения. Накопление 0 → 5 → 10 и сохранность первой партии пока не проверены.

Диагностика содержит два завершённых интервала `localizer.photo`, но это не два сохранённых результата пополнения: в SQL подтверждён только один checkpoint. Отдельный результат локализатора нельзя считать готовым товаром или опубликованным поисковым вектором.

Исправленное ожидание общего socket прошло в реальном запуске: host принял START и начал ML. До исправленного сравнения итоговых SQL tuple успешной партии выполнение не дошло. Сам факт остановки по ресурсу не является подтверждением успешного полного runner.

## Что известно о нагрузке

Guard сохранил110наблюдений:103OK,5WARNING и2STOP. В пяти WARNING наблюдалось системное давление памяти `pressure=2`. Максимумы сохранённых успешных замеров: RSSaggregate1481392128байт (около1,38GiB), MPSdriver3976462336байт (около3,70GiB). Это ниже установленного потолка6GiB; зафиксированного превышения лимита в этих замерах нет.

Точная причина первого STOP — **UNKNOWN**. `MacResourceObserver` возвращает STOP как при превышении пределов/критическом давлении, так и при ошибке обязательного наблюдения: OS command, process identity, telemetry identity/freshness и другие проверки. Код перехватывает исключение без сохранения его типа и причины. Сам журнал статуса не позволяет различить эти варианты.

Первая запись STOP содержит предыдущий успешный `last_sample` с pressure1, RSS699809792 и MPS2711306240байт. Эти значения не доказывают состояние ресурсов в момент неуспешного измерения. Нельзя заключить, что STOP был ошибочным, что был OOM или что виноват конкретный предел. Предупреждения pressure2 предшествовали остановке, но причинная связь не установлена.

Parent diagnostics:52записи, все measurementOK, итог incomplete=false; максимальная измеренная длительность одного diagnostic sample1,088с. Системный swap остался2992111616байт, pageouts выросли78158→78673. Это общесистемные показатели, они не приписываются только нашему процессу. Подробная ML-диагностика относится только к локализации:25записей/all measurementOK; финальный worker footer UNKNOWN. По этому неполному запуску нельзя сравнить нагрузку трёх encoder-моделей или оценить масштабирование на674фото.

## Проверка и очистка

До выдачи гранта проверены оба точных SHA, закреплённый SHA runner, frozen code/input inventories, отсутствие host/workers и probe-контейнеров; начальное давление памяти1. Во время выполнения код и лимиты не менялись.

Runner удалил принадлежащую серии PostgreSQL и секреты. Независимая проверка подтвердила:0собственных host/worker/viewer и процессов их групп,0probe-контейнеров, socket отсутствует, secret env и оба target descriptor отсутствуют. Грант A использован; Bgrant отсутствует. Приватные logs, результаты, telemetry и checkpoint-файлы сохранены. БД удалена, поэтому оставшиеся файлы не являются готовым контуром для RESUME.

Продуктовый код не менялся; последняя регрессия163теста относится к предыдущей проверке и не повторялась. Review не проводилось. Рабочая БД/корпус/Web, модели и лимиты не менялись; автоматического повтора нет.

## Следующий шаг

Выяснить, какое обязательное наблюдение вызвало STOP: текущего журнала для этого недостаточно. Для устранения пробела потребуется ограниченная диагностика причин resource observation без раскрытия исходных данных и без ослабления защиты. Решение об изменении runtime и новый запуск оформляются отдельно. Этот отчёт не разрешает новый START, RESUME, увеличение лимитов или третью партию.

Уточнение 2026-10-15: [разбор кода и измерений](resource-stop-diagnosis.md) установил механизм первого STOP — ошибка обязательного наблюдения, а не итоговая ветка общих RSS/MPS/pressure ceilings. Среди обязательных проверок есть component RSS ceiling, его превышение не исключено. Точная проверка остаётся UNKNOWN. Добавлена диагностика будущих sensor STOP; старые файлы не изменены, нового ML не было.
