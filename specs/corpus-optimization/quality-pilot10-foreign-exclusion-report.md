# Исключение посторонних масок из пилота10

2026-10-19. STANDARD. **OFFLINE_ABLATION_COMPLETE**.
Прямое поручение владельца — исключить подтверждённые посторонние маски
и пересчитать выдачу после [визуального разбора](quality-pilot10-error-analysis.md).
Это диагностический опыт с ручным выбором областей, не автоматический фильтр.

## Итог

После совместного исключения для основной комбинации трёх моделей розовый
френч занял1-е место вместо4-го по среднему по назначенным парам.
Правильных top-1 стало2/5 вместо1/5. Top-5 остался2/5, top-10 —3/5.
Текущая формула по всем областям запроса оставила top-1/5/10 на уровне1/5;
розовый пример по ней опустился с43-го на51-е место.

Очистка исправила конкретный случай при парной нормировке, но не решила
остальные промахи и не доказывает качество будущего автоматического фильтра.

## Заранее зафиксированный состав

Из сохранённых DTO исключены только четыре маски трёх посторонних объектов:

- Запрос5: маски6/7 одного розового кольца; сохранены пять ногтевых масок1–5.
- Ожидаемое фото запроса5: флакон клея5; сохранены четыре ногтевые маски1–4.
- Каталожный лидер бордового запроса4: кольцо9; сохранены области1–8.

Номера запросов соответствуют [пилотному отчёту](quality-pilot10-report.md).
Список выбран по ранее просмотренным маскам, сохранён до scoring и после
результатов не расширялся. Дубли, смешанная маска ногтя с пальцем и частично
видимые ногти не исключались; отсутствующие маски не восстанавливались.
Остальные81 каталожное фото и девять запросов не редактировались.

Рассчитаны пять вариантов: baseline, только кольцо запроса, только клей,
только кольцо конкурента и все посторонние вместе. Каждый вариант включает
все10 запросов против83 товаров, обе формулы и7 комбинаций моделей.
Исходные labels/IDs/фото/векторы/формулы сохранены; менялся только набор
используемых областей в временных DTO. Ordinals перенумерованы с явным
соответствием исходным, значения оставшихся векторов сохранены точно.

## Изолированные изменения: розовый френч, три модели

| Вариант | Областей запроса / ожидаемого фото | Ранг: текущая формула | Ранг: по парам | Score: текущий / по парам |
|---|---|---:|---:|---|
| Baseline |7 /5|43|4|0,6114 /0,8559|
| Только кольцо запроса |5 /5|8|8|0,8559 /0,8559|
| Только клей |7 /4|52|1|0,5054 /0,8844|
| Только кольцо конкурента |7 /5|43|4|0,6114 /0,8559|
| Все посторонние |5 /4|51|1|0,7075 /0,8844|

Удаление кольца только из запроса сохраняет score ожидаемого товара по парам,
но улучшает scores части конкурентов: у них исчезают слабые сопоставления
кольца. Поэтому парный ранг меняется4→8, хотя собственный score не падает.

Удаление клея оставляет четыре ногтя. Назначение перестраивается: вместо
пары ноготь–флакон выбираются четыре ногтевые пары. Их среднее0,8844 становится
наибольшим. При совместной очистке среднее остаётся тем же, но текущая формула
делит сумму четырёх пар на пять областей запроса:0,8844×4/5 =0,7075.
У лидера текущей формулы score0,8791; в результате ожидаемый товар на51-м месте.
Это не основание сохранять флакон ради количества сопоставлений.

Удаление кольца у бордового конкурента не изменило положительные ранги
основной комбинации. Это не доказывает бесполезность очистки: исчезла
предметно неверная область, но оставшихся ногтей и их scores достаточно
для сохранения порядка в этих сравнениях.

## Все положительные запросы после совместной очистки

Основная комбинация: OpenCLIP B32 + DINOv2 B14 + SigLIP2 B16/224.

| Запрос | Текущий ранг: до → после | Парный ранг: до → после |
|---|---|---|
|1: повтор каталожного снимка |1 →1|1 →1|
|2: вишни |57 →57|40 →41|
|3: нюд |80 →80|7 →7|
|4: бордовый дизайн |67 →67|15 →15|
|5: розовый френч |43 →51|4 →1|

Вишни сдвинулись на одно место: очищенный другой товар поднялся в его рейтинге.
Следовательно, адресная очистка каталога влияет и на запросы, чьи собственные
маски не менялись. MRR по парам вырос0,2969→0,4468; по текущей формуле
изменился0,2136→0,2129. Пять ожидаемых товаров различны; macro-by-product
для top-k совпадает с долей по запросам. Объединение top-5 двух списков
сохранило попадание у2/5 положительных запросов.

## Семь комбинаций: парная формула после совместной очистки

| Модели | Top-1 до → после | Top-5 до → после | Top-10 до → после | Ранг розового френча до → после |
|---|---|---|---|---|

Все семь комбинаций по-прежнему ставят повтор исходного снимка первым.
Ещё один top-1 у SigLIP2 — бордовый дизайн; у DINOv2 и трёх комбинаций —
розовый френч. Ни одна комбинация не получила правильный top-1 для всех5.
Потери top-5/top-10 у двух комбинаций связаны с перемещением очищенного
товара выше других ожидаемых записей. Выбор модели или формулы продукта
по этому диагностическому набору не выполнялся.

## Отрицательные запросы

Для основной комбинации после совместной очистки лидеры и их scores
всех пяти отрицательных запросов остались прежними по обеим формулам.
Другие позиции рейтингов могут меняться. Полные scores/margins сохранены
для всех вариантов/комбинаций. Порог отсутствия товара не задан;
корректность отказа и false acceptance rate не оценивались.

## Проверка и границы

Baseline точно воспроизведён для10 запросов/7 комбинаций/2 формул.
Проверены4150 сравнений с core и29050 назначений. Отдельная проверка
вырезает строки/столбцы из исходных similarity matrices, без subset-DTO helper,
и воспроизводит29050 результатов назначения/оба score. Подтверждены
сохранность оставшихся векторов, отсутствие изменений не затронутых
сопоставлений, неизменность остальных девяти запросов в query-only варианте
и невозрастание текущего score после удаления только каталожных областей.
Некорректные subset selections отвергаются, три проверки PASS.

Все пять вариантов рассчитаны за65,235с при deadline600с.
Исходные SHA/code pins сохранены; torch/transformers/open_clip/psycopg
не импортировались. Данные/private contract, результаты и verifier:
`artifacts/corpus-replenishment/pilot10-foreign-exclusion-20261019/`.
Вычисления выполнены на копиях DTO, рабочий каталог83 и его экспорт не менялись.
Новых ML/SQL, установки зависимостей, изменения масок/формул/labels,
автоматического фильтра, рабочей активации, commit/push нет.

Это адресная очистка по уже известным ошибкам. Пилот содержит повтор снимка
и используется для диагностики; независимая оценка фильтра не проведена.
Эффект очистки подтверждён для розового примера, достаточность фильтра для
поиска в целом не подтверждена. Пропуски каталожных ногтей и различение
похожих дизайнов остаются отдельными проблемами. Самопроверка выполнена;
независимое review не проводилось (STANDARD).
