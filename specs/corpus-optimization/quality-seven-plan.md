# Прогон новых запросов на семи комбинациях моделей

2026-10-15. STANDARD. Основание: владелец передал фото и поручил продолжать по плану;
действует разрешение выполнять изолированные проверки пакетом.

## Границы и порядок

1. Проверить семь PNG, owner mapping и membership по сохранённому manual20;
   сравнить SHA файлов и RGB pixels со всеми двадцатью фото каталога.
2. Расширить экспериментальный capture до frozen count 1–7, включая запросы
   отсутствующих товаров, по TDD. Штатный поиск и формула неизменны.
3. Frozen копия ранее проверенного runtime: тот же catalog SHA,
   profile/model revisions/preprocessing/I. Один новый capture семи фото,
   максимум 220 admissions (7 × (1 + 3 × 10) + 3 загрузки), 600 секунд.
   Сохранять полные query vectors; не выполнять inference повторно для комбинаций.
4. Пересчитать assignment и ranking всех двадцати товаров для семи непустых
   комбинаций. Сверить baseline с match_photos. Для присутствующих товаров —
   rank/top-k; для отсутствующих — только diagnostic scores/margins, без
   выдуманного порога отказа. Несколько фото одного товара не считать
   независимыми товарами.
5. Сохранить частное evidence, агрегированный отчёт и удалить owned runtime/БД.

## Среда и ограничения

Исходная служебная БД недоступна. Допустима одна новая disposable PG на уже
локальном image SHA из предыдущих проб: без pull/install, 512 MiB/1 CPU/128 PIDs,
localhost port, собственные container/volume labels. В ней только миграции до
0009 для проверок query runtime; пользовательские товары не импортируются.
Собственный именованный volume нужен существующему OwnedTarget, в finally
удаляется вместе с контейнером. Это изолированная тестовая инфраструктура,
не рабочая БД и не пересборка каталога.

Старые owner claims не используются. Новый package/command/permit SHA до ML,
one-shot claim; expiry 1200 секунд. Model/I code pins проверяются перед запуском.
Пределы I RSS 6 GiB, backend RSS 5 GiB; combined RSS ужесточён с исторических
10 до 6 GiB. Pressure/freshness/storage/swap guards сохраняются; STOP означает
сохранить частичный результат, без автоматического перезапуска.
Максимум контура 900 секунд плюс cleanup до 30 секунд.

Совместный capture измеряет только общий runtime трёх моделей. Он не измеряет
ускорение и RAM каждой отдельно отключённой комбинации; offline scoring time
не выдаётся за end-to-end latency. Такие замеры требуют отдельного bounded
пакета после анализа качества, если набор различает варианты.

Экспериментальный suite и релевантные безопасные tests frozen runtime;
Ruff/Markdown links/markers/diff. Независимое review не требуется для STANDARD.
Фото, source IDs, labels, vectors, detailed ranking и секреты остаются вне Git.
