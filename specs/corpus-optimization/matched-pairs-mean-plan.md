# Среднее по сопоставленным парам: план диагностического сравнения

2026-10-15. STANDARD. **EXECUTED / OK**. [Результат](matched-pairs-mean-report.md). Владелец согласовал проверку именно влияния
нулей за несопоставленные области: сравнить текущую формулу со средним только
по сопоставленным парам. [Исходный результат](remaining-quality-report.md),
[разбор первых мест](top-candidates-review.md).

Семь прежних запросов, двадцать прежних фото, семь комбинаций моделей.
Исходные области/векторы/labels не меняются: кольцо, дубли и неоднозначные
фрагменты остаются, чтобы не смешать изменение знаменателя с очисткой данных.

- Исходный score: сумма оценок выбранных пар / число областей запроса n.
- Диагностический score: та же сумма / число сопоставленных пар k.
- Назначение пар и их оценки сохраняются. Это среднее по выбранным алгоритмом
  парам, не среднее только по вручную признанным правильными совпадениям.
  При текущем алгоритме k = min(n, m), где m — области каталожного фото.
- Отказ по порогу, минимальное число пар, coverage bonus и иные варианты не добавляются.

Полный исходный baseline должен воспроизвестись. Для каждого query/catalog
рассчитываются pair matrices, проверяется прежнее назначение и score; для всех
140 пар трёхмодельный baseline сверяется с core. Новое ранжирование использует
прежний tie-break. Независимые арифметические проверки: полный match не меняет
score, неполный match даёт old_score = new_score × k/n, значения остаются [0,1].
Контрольные примеры до расчёта: [0,9; 0,7; 0; 0] при двух выбранных парах дают
0,4 по старой формуле и 0,8 по новой; при четырёх выбранных парах формулы равны.

Проверяются все рейтинги: ранги/top-k трёх положительных запросов двух товаров,
первые места и число пар, подъём ложных кандидатов, в особенности единственного
каталожного фото с одной областью. Распределение исходного каталога по числу
областей: 1×1, 2×1, 3×3, 4×6, 5×2, 8×2, 10×5.
Для четырёх отсутствующих запросов — scores/margins без вывода о корректном отказе.
Общий offline deadline 600 с, без ML/БД/установки и новых векторов.

Продуктовая формула не меняется. Результат не является принятием новой политики;
приватные детали остаются в ignored artifacts. Коммит/push/cutover/50–100
не выполняются. Независимое review не проводилось.
