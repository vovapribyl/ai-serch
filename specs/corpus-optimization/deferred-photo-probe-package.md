Проверка ошибки runner воспроизведена без нового ML: export_deferred_batch читает
сохранённый каталог через private_json из CLI. Его JSON_LIMIT=65 536 bytes
предназначен для bootstrap-дескрипторов; фактический экспорт — 209 337 bytes.
Поэтому чтение отказало уже после успешной записи экспорта. Тот же parser
использует подготовленный runner при чтении каталога; исправление только первого
места оставило бы второй отказ. Синтетические маленькие fixtures подготовки
этот размер не покрывали.

Отдельная read-only проверка прочитала ограниченный сохранённый экспорт, повторила
проверки frozen verifier и проверила checkpoints и очистку. Статус runner и
подписанные исходники не переписывались. Код продукта этой задачей не менялся.

в каталоге подготовки, указанном выше. Сырые ID и изображения в документ не внесены.
