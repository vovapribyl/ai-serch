# Ручной стенд для уточнения ожидаемых товаров

2026-10-12. FULL. Владелец попросил запустить поиск для перепроверки сохранённых
фото. Это разрешение на одну ограниченную ручную сессию, без отключения модели.

## План-контракт

Подготовить новый частный frozen-пакет из ранее проверенного image-only кода →
проверить SHA, совместимость каталога и сборку без model inference → один
независимый read-only reviewer → cold bootstrap → открыть UI владельцу.

Текущая ветка `codex/upload-optimiz` не содержит реализацию manual20. Код стенда
копируется без функциональных изменений в отдельный временный runtime snapshot,
не в дерево этой ветки. Code pins и assembly paths должны соответствовать именно
этому snapshot. Прежний consumed job/permit не переиспользуется; старые данные
и процессы других задач не меняются.

Каталог: сохранённые 20 товаров/112 областей/336 векторов, те же модели, crop,
dtype и ranking. Лимиты: 20 поданных фото, 623 admissions, 3600 секунд,
20MiB/2359296 pixels, прежние region/solver/RSS/storage/pressure STOP.
Никаких automatic retry/restart, corpus build, READY100 или publication.
Существующая инфраструктура может читать размер изолированной БД и свободное
место VM для resource guard; записи в БД и смена active pointer не входят.

Запросы выполняет владелец. Наблюдение выдачи помогает вспомнить товар, но
само по себе не подтверждает правильное совпадение. Expected goods нужно
подтвердить по исходному фото и каталожному изображению; «нет»/«не уверен» допустимы.
Эта сессия не является сравнением качества двух и трёх моделей.

## Проверка

SHA копируемого кода против прежнего frozen job/assembly; новый job/permit и
отсутствие consumed claims; catalog bytes/models/vectors не изменены;
model-free assembly и существующие manual/guard tests; HTTP health/UI после
bootstrap, отсутствие agent query и zero admissions до передачи владельцу.
Проверки SDK import не считаются ML inference или quality acceptance.

Приватные файлы 700/600 вне Git. Отчёт содержит только safe aggregate evidence.
После STOP окно не перезапускается автоматически.
