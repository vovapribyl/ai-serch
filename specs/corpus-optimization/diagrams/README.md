# Диаграммы AS-IS / TO-BE

Все подписи процесса — на русском; имена моделей и кодовые идентификаторы
сохранены. Светлый фон, тонкие линии, один синий акцент.

**Редактируемый источник содержания — `descriptions.json`.** В нём находятся
шаги обзоров, роли, сообщения sequence и границы повторения. После правки выполнить
из этой папки `python3 render.py`: генератор читает JSON и создаёт шесть SVG,
шесть PlantUML-исходников и `preview.html`. JSON при генерации не перезаписывается.

`render.py` задаёт только оформление. SVG подготовлены собственным локальным
layout; они не являются результатом компиляции PlantUML. `.puml` также можно
редактировать в PlantUML, но повторная генерация заменит их содержимым JSON.
Для согласованности двух форматов изменения процесса вносятся в JSON.

| Файл | Назначение |
|---|---|
| `as-is-overview` | Существующий успешный путь обработки фото |
| `as-is-sequence` | Вызовы участников при обработке одного фото |
| `to-be-overview` | Предлагаемые стадии небольшой партии |
| `to-be-sequence` | Успешная партия и завершение собственных workers |
| `to-be-resume` | Hard STOP и отдельно разрешённое продолжение |
| `to-be-publication` | Автоматическая атомарная публикация готового товара |

SVG имеют заголовок/описание для доступности и вставлены в Markdown-документы.
Для визуальной проверки `preview.html` содержит все шесть схем. На узком экране
сложную sequence можно открыть отдельно или увеличить масштаб.

XML/SVG accessibility и соответствие сообщений описаниям проверены.
PlantUML проверен только структурно: Java/PlantUML отсутствуют, компиляция не
выполнена. Публиковать `.puml` как прошедшие parser/render validation нельзя.
