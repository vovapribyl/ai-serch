# Диаграммы HLD

`descriptions.json` — редактируемый источник содержания. `render.py` создаёт
SVG, PlantUML-исходники и `preview.html`. Для sequence используется существующий
layout из `../diagrams/render.py`; генератор не изменяет исходники TO-BE.

| Файл | Назначение |
|---|---|
| `components` | Компоненты, процессы и основные связи с хранилищами |
| `publication` | Проверка редакции, активирование snapshot и чтение поиском |
| `ports-adapters` | Ядро, входные/выходные порты, адаптеры и направление зависимостей |

SVG подготовлены локальным layout, не компилятором PlantUML. `.puml` редактируются
через общий JSON при последующей генерации. Java/PlantUML отсутствуют, компиляция
не выполнялась. Диаграммы относятся к утверждённому HLD v1.1 и не доказывают runtime.
